# zaidrahim.me — Zaid Rahim · AI/ML Engineer portfolio

Static site (HTML/CSS/JS, no build step). Deployed via GitHub Pages to https://zaidrahim.me/

## Structure
- `index.html` — page shell, SEO/OG/JSON-LD
- `assets/js/data.js` — content model (edit this to update projects/skills/repos)
- `assets/js/main.js` — rendering + animation
- `assets/css/style.css` — design system
- `CNAME` — custom domain for GitHub Pages

## Local preview
```bash
python3 -m http.server 8000
```
